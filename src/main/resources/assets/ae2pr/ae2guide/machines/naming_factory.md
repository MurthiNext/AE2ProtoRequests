# 名称压印工厂

<BlockImage id="ae2pr:naming_factory" scale="3" />

名称压印工厂是比<ItemLink id="ae2:inscriber" />更加高效的、批量命名物品的设备！

它和压印器效果差不多，但拥有64并行，放入已经携带名称的<ItemLink id="ae2:name_press" />即可开始重命名。

主要是用在<ItemLink id="ae2pr:crystal_assembly_line" />这样可能出现两格材料完全相同，但又强制有序配方的机器上的，不命名可能导致物品无法正确按配方发配。

*实际上，此模组已尽可能避免这种配方，如果你正在游玩 GregTech Modern，这会有用的。*
