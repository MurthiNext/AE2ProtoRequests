# 源始终端

<ItemImage id="ae2pr:proto_terminal" scale="3" />

<ItemLink id="ae2pr:proto_terminal" /> 是一件有些特殊的物品，右键可以打开 AE2 Proto Requests 的剧情树。

## 一键搭建多方块

手持源始终端，对着多方块机器的主机 **Shift + 右键**，终端会尝试补全该多方块结构。

- 正确的方块会被保留，不消耗材料；
- 空气与可替换方块（草、雪、水等）替换为该格的首选方块，并消耗材料；
- 被其他方块或实体占据的格子跳过，并在聊天栏提示，不消耗材料；
- 位置正确朝向不符的方块跳过并单独提示，需自行摆正，不消耗材料；
- 创造模式不消耗任何材料；
- 终端会自动识别并选择结构可能的镜像方案。

有关多方块结构，详见[多方块结构](../multiblocks/multiblocks_index.md)。
