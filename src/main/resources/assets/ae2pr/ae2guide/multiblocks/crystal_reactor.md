# 水晶反应器

<GameScene zoom="3">
  <ImportStructure src="crystal_reactor.nbt" />
  <IsometricCamera yaw="90" pitch="10" />
</GameScene>

*~看哭十亿 Minecraft 老玩家。~*

类似于 Minecraft 旧版本的下界反应器，使用陨石+赛特斯石英块+高能核心复刻该多方块结构，并空手右键核心，即可激活它。

反应启动后，水晶母岩会侵蚀以核心为圆周8格半径、向下4格纵深的方块。

可出现的母岩包括赛特斯石英母岩、紫水晶母岩、过载水晶母岩（来自 AE2LT）、盈能水晶母岩（来自 Neo ECO AE Extension）。

无暇：有瑕：开裂：损坏的出现比例为1:4:8:32.
