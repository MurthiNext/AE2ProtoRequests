# 多方块结构

你也许已经意识到了，这个模组有点像……GregTech？

放心，不会太难的。

## 概述

[仓室与总线](chambers.md)可以使机器获得外部输入输出的能力。

单方块机器使用加速卡所实现的逻辑和 AE2 原版相同。

多方块机器采用**有损超频**：每张加速卡使速度 **+50%**，但单次作业的耗能变为 **×4**。

## AEV 阶段

[水晶装配线](crystal_assembly_line.md)，AE2 Proto Requests 科技树的起点，利用子网与优先级驾驭这台精密机器吧！

[高反应性熔岩冶炼炉](high_reactivity_lava_smelter.md)，传统而先进的炼钢机器！（当然，不止炼钢。）

[物质相变仪](matter_phase_transformer.md)，以高能粒子束流改变物质形态，说人话就是物质液化器。

[水晶反应仓](crystal_reaction_chamber.md)，灵感来自于 Advanced AE 的反应仓，但这个更大，更强！并且拥有并行！

[晶能工作站](crystal_workstation.md)，*或称精密组装机*，迈向 XPV 阶段前的最后一个多方块机器！
