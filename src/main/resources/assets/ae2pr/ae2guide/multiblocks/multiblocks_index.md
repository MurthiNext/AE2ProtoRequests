# 多方块结构

你也许已经意识到了，这个模组有点像……GregTech？

放心，不会太难的。

## 概述

[仓室与总线](chambers.md)可以使机器获得外部输入输出的能力。

单方块机器使用加速卡所实现的逻辑和 AE2 原版相同。

多方块机器采用**有损超频**：每张加速卡使速度 **+50%**，但单次作业的耗能变为 **×4**。
