# 材料

当第一颗陨石落在 Minecraft 的大地上……它其中的赛特斯石英水晶又来自何方？

AE2 Proto Requests 添加了基于陨石与赛特斯石英水晶的科技树，逐渐解锁高效配方的同时，也让关于陨石来源的故事愈发清楚。

*借由他人，寻找自我。*

## AEV 阶段

首先，你需要获得 AE2 Proto Requests 的*第一台加工机器*（存疑）：[异星熔岩](alien_lava.md)，并用它制取[陨钢锭](meteor_steel.md)。

在开采陨石的时候，你还能得到一些[锆英石](zircon.md)。锆英石本身就很有用，也可进一步加工成金属单质[锆](zirconium.md)。

有了这两样东西，你的旅途算是正式开始了。
