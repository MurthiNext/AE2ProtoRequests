# 材料

当第一颗陨石落在 Minecraft 的大地上……它其中的赛特斯石英水晶又来自何方？

AE2 Proto Requests 添加了基于陨石与赛特斯石英水晶的科技树，逐渐解锁高效配方的同时，也让关于陨石来源的故事愈发清楚。

*借由他人，寻找自我。*
