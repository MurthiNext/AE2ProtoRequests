# 异星熔岩

异星熔岩（~~深色熔岩~~）是初期简单的热力能量来源，向熔岩中播撒约半组陨石粉，使这“液态石头”的性质变得愈发稳定……陨石中的元素在高温下产生了一些简单的反应，这使异星熔岩具备了基础的可控性。

用它来炼钢吧！

哦对了，由于操作过于古法，这导致其有一定的使用耐久，耐久用尽后，异星熔岩便会退化回普通的熔岩——在它变亮后可不要再着急往里丢材料了！
