# 陨钢锭

**AEV 级材料**

将陨石粉与我们所熟知的钢进行初步融合，诞生出第一份来自系外行星的材料，这便是陨钢！

AEV 阶段，大部分机器与机器方块都需要用到陨钢，你的第一份陨钢大概率会来源于 <ItemLink id="ae2pr:alien_lava_bucket" />，此后你可以用更可控的办法制取它。
